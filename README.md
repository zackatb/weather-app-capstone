# capstone Weather App

A simple and visually appealing weather application that provides current weather details, maximum and minimum temperatures, and detailed hourly graphs for weather and humidity throughout the day.

## Features

- **Current Weather**: Displays the current temperature, weather conditions, and location.
- **Maximum and Minimum Temperatures**: Shows the day's high and low temperatures.
- **Detailed Graphs**:
  - Hourly temperature graph for the day.
  - Hourly humidity graph for the day.
- **Responsive Design**: Fully optimized for desktop and mobile devices.

## API Used

This app utilizes the [Open-Meteo Weather API](https://open-meteo.com/) for fetching accurate and up-to-date weather data.
